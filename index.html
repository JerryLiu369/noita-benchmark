操作与机制

如何在这座山下活得更久一点

  • 移动：A/D 或 ←/→；跳跃：W / ↑ / 空格；在空中按住跳跃键可悬浮，悬浮燃料会消耗并在落地后回复。
  • 施法：鼠标瞄准，按住左键；数字键 1-4 或滚轮切换持有的魔杖。
  • 魔杖：魔杖只是容器。槽位里可以放弹体、修饰、多重施法与触发法术，顺序决定连锁（例：多重施法 → 火焰轨迹 → 追踪 → 火花弹）。
  • 编辑：在圣山的安全房间内按 E 打开魔杖编辑台；获得「随身工匠」祝福后可以随时编辑。
  • 拾取：靠近金币自动吸取；靠近法杖/宝箱/血瓶按 F 拾取。
  • 圣山：每一层之间的圣山提供全回复、魔杖编辑与三选一永久祝福。
  • 死亡：生命归零即永久死亡，结算界面会写明死因（烧死 / 溺死 / 中毒 / 被击杀 / 被压死…）。

提示：把鼠标悬停在材料上会在左上角显示材料名称与类别；油、酒精易燃，水能灭火，酸会溶解岩石。

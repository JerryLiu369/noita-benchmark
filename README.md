# PIXEL ALCHEMIST · 像素炼金术士

一个零后端、纯前端的 Noita 风格像素物理地牢游戏。项目只有 `index.html`、`styles.css`、`game.js` 三个文件，通过任意静态文件服务器打开即可，不需要安装依赖，也不需要联网。

## 运行

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 操作

| 按键 | 作用 |
| --- | --- |
| `A` / `D` | 左右移动 |
| `W` / `空格` | 跳跃；空中按住 = 悬浮飞行 |
| `鼠标` | 瞄准，按住左键施法 |
| `1` ~ `4` | 切换魔杖 |
| `E` | 开宝箱 / 拾取魔杖 |
| `Q` | 饮用血瓶（+35 生命） |
| `R` | 打开魔杖编辑台（须在圣山或已获得祝福），拖拽法术到槽位 |
| 手机 | 左下方向键移动，右下按钮施法，在画面上拖动可自由瞄准 |

## 已实现

- **像素物理**：34 种材料的元胞自动机，密度分层（油浮于水、血沉于水下）、酸腐蚀一切、火焰沿可燃物蔓延并熄灭、熔岩遇水生成石头+蒸汽、毒气上浮、砂雪下落、水/油流动与蒸发。每种材料按区域调色板 + 噪声纹理渲染，一眼可辨材质。
- **黑暗与光照**：洞穴区域环境光很低，火把、火焰、熔岩、发光法术与玩家法杖光都是径向渐变光源，经离屏光照缓冲以 multiply 合成、辉光层以 additive 叠加。
- **法杖组装**：可捡法杖、圣山编辑台拖拽法术到槽位；**10 种弹体**（火花弹、魔法箭、火焰投射、爆裂法球、锯刃轮、回旋盘、孢子团、冰晶镖、追踪弹、挖掘射线）、**8 种修饰**（伤害/速度强化、巨型化、穿透、弹射、爆炸弹、沉重化、散射）、**2 种触发**（定时触发、爆裂触发：载体弹在计时结束或命中时迸出载荷）、**3 种多重施法**（二重/三重/五重）。
- **五层向下探索**：矿坑 → 煤坑 → 真菌洞窟 → 雪峰地底 → 熔岩深渊，层间为圣山安全屋（恢复生命、重置法术、编辑魔杖、三选一祝福）；金币、血瓶、宝箱分布其中，越深越危险。
- **死亡结算**：死亡写明死因（被烧死 / 被熔岩烧死 / 溺死 / 压死 / 毒死 / 被酸液腐蚀 / 被击杀…）与所在区域、深度、存活时间、击杀数、金币，然后整局重开。
- **打击感**：屏幕震动、命中闪光、粒子爆裂、伤害数字，全部音效由 WebAudio 实时合成（无音频文件）。
- **敌人 5 种以上**：冲锋近战、远程弹幕、飞行、自爆、潜地等区分行为。
- **桌面键鼠 + 手机触屏**双输入。

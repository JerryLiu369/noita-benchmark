# ASHFALL · 灰烬竖井

一个零后端、纯前端的 falling-sand roguelite 像素地牢（Noita 机制复刻，原创代码/像素/命名）。
只有三个文件：`index.html` + `game.js` + `styles.css`，无构建、无 npm、无外部资源（含音效均为 WebAudio 合成）。

## 运行

```bash
python3 -m http.server 4173
# 访问 http://localhost:4173/
```

桌面键鼠与手机触屏均可。触屏：左下方向/跳跃键、右下开火键（带自动索敌）、换杖/改杖键，滑动画面瞄准。

## 已实现（对照 Noita 核心机制）

- **像素物理**：26 种材料。液体按密度分层（油浮水上、血沉水下、酸更沉、熔岩最沉）；
  火沿可燃物蔓延并熄灭成烟；熔岩遇水/冰/雪成岩+蒸汽；毒液上浮毒气；酸腐蚀除圣所砖外一切固体；
  沙/雪/火药粉末坠落堆积、遇水下沉；蒸汽上升冷凝。地形为哈希噪声质感渲染（矿物斑点+液面高光），非纯色块。
- **黑暗与光照**：洞穴按深度压暗（地表接近明亮→深层约 0.8 不透明），玩家、火把/水晶、熔岩/火焰、
  发光弹体、爆炸闪光均为径向渐变光源（destination-out 打孔 + 暖色 additive 辉光），圣所较亮。
- **法杖组装**：4 杖位，牌库式结算（修饰/多重/触发/弹体/ utility，洗牌与充能回绕）。
  9 种弹体（火花/飞箭/炎爆弹/开山雷管/光钻/泡泡/雷弧/水注/酸蚀球）、9 种修饰（追踪/火舌/弹跳/
  暴击/爆裂/微光/穿透/增幅/疾速）、3 种多重（双重/三重/散射）、2 种触发（触发/定时）、
  2 种 utility（闪现/治疗）。触发可把后几张打包成命中/定时释放。可拾取野外魔杖（E 拾取/交换/丢弃），
  圣所内拖拽改杖（支持点击与 HTML5 拖放），野外需“魔杖工匠”祝福。
- **探索与死亡**：地表→矿坑→煤坑→真菌洞→雪山→熔岩湖→终焉 vault，层间发光圣所（三选一祝福+改杖+血池），
  越深敌人血攻越高；金币/法术卷轴/生命之心/血瓶/宝箱/野外魔杖；死亡 overlay 写明死因
  （烧死/葬身熔岩/溺死/毒死/溶解/炸碎/压死/被某敌人击杀/被深渊之眼注视）并整局重开；终焉有 Boss 战与胜利结算。
- **打击感**：屏幕震动、命中闪白、伤害数字、血液/火星/碎石粒子、WebAudio 合成音效（施法/爆炸/命中/
  受伤/拾取/传送/祝福/死亡/胜利，可按 M 静音）。
- **敌人（7 种）**：爬行者（近战冲锋跳跃）、喷吐者（远程弹幕保持距离）、洞穴蝠（正弦飞行冲撞）、
  自爆孢（接近引信自爆）、潜地虫（穿软土潜地+突刺）、重甲守卫（高血+三连弹）、深渊之眼 Boss
  （扇形弹幕+狂暴加速+召唤小蝠）。敌人会被熔岩/酸/火点燃受伤，会掉血渍。
- **状态**：着火（按最大生命百分比扣血，水可灭）、中毒、湿润、溺水氧气条、挤压伤害。

## 操作

A/D 移动，W/空格/↑ 飞行，鼠标瞄准+按住左键施法，1-4 换杖，E 拾取魔杖/开关改杖，M 声音。
圣所内按 E 打开改杖面板；祝福在进入圣所时自动三选一（或按 1/2/3）。

## 实测（2026-09-22，无头 Chrome）

`?autotest=1` 内置同步自检 11 项全部 PASS：移动/跳跃/施法/触发载荷/油水密度分层/
熔岩遇水成石/光源>3/实弹击杀敌人/近战击杀计数/死亡 overlay 与死因“烧死”。
另有 `?play=1` 游玩截图（出生/战斗/改杖面板/死亡结算）见 DONE.md。

# PIXEL ALCHEMIST

一个零后端、纯前端的 Noita 风格像素物理地牢原型。项目只有 `index.html` 和 `game.js`，双击或通过任意静态文件服务器打开即可。

## 运行

```bash
python3 -m http.server 8765
```

然后访问 `http://localhost:8765/`。不需要安装依赖，也不需要联网。

## 已实现

- 320×180 低分辨率像素画布，CSS 像素放大，桌面键鼠与手机触控。
- 8 个纵向生物群系、Holy Mountain 休整区、随机种子、深度推进和首领房。
- 岩石、泥土、砂、雪、水、油、熔岩、血、毒液、木头、火、烟、蒸汽、冰、金矿等材料的简化像素自动机。
- 可破坏地形、液体流动、砂/雪下落、熔岩遇水成石、火焰扩散、蒸汽上升。
- 4 把魔杖，每把有法术槽、魔力、施法间隔、回复速度；支持多重、追踪、爆炸、火焰、弹射、暴击、节能等修饰。
- 火花弹、魔法箭、炎爆、不稳定炸弹、光明钻头、水流、散射弹、链式闪电、短距传送。
- 近战、远程、飞行敌人和终焉之眼首领；金币、法术拾取、永久死亡和胜利状态。
- 6 种可叠加祝福、圣山魔杖编辑台（交换槽位、加入随机法术）。

## 研究依据与边界

研究摘要和来源见 `report-source.md`。实现使用原创代码、原创像素绘制和原创名称，仅复刻公开描述的系统关系；没有复制 Noita 的原始资源、音频或源代码。原作包含数百种法术、材料、敌人、秘密区域和精确的内部数值，本项目把最能决定手感的系统做成了可玩的浏览器版本，并明确保留了近似数值。

# 烬渊 Emberdeep — 像素物理·掘进肉鸽（Noita-like）

纯前端、零构建的单目录网页游戏：`index.html` + `game.js` + `styles.css`，无任何外部依赖/素材/网络请求。
像素、材质、光照、法术组装全部在 `480×270` 逐帧模拟的 `512×2256` 世界中运算。

> 本作复刻 Noita 的**机制手感**，但世界观、命名、美术均为原创（烬渊 / 岩脊兽 / 熔渊巨眼……），未使用任何 Noita 素材或专名。

## 运行

```bash
cd <本目录>
python3 -m http.server 4173
# 浏览器打开 http://localhost:4173
```

直接双击 `index.html` 亦可运行（同源无关），但推荐 HTTP 方式。桌面与手机浏览器均支持。

## 系统一览

- **像素物理**：约 30 种材质，密度分层（油浮于水、血沉底、酸蚀万物）；火沿可燃物蔓延、被水浇灭；**熔岩+水→岩+蒸汽**；毒气上升、遇火爆燃；沙/雪粉尘沉降；TNT 链爆；蒸汽遇冷顶回凝成水。
- **光照**：洞穴近乎全黑；营火/灯柱/熔岩/发光菌/火系法术都是**径向渐变光源**，叠加于 2×下采样的光图上并做两遍盒式模糊，Bayer 有序抖动压黑边。
- **法杖组装**：10 投射物 + 10 修饰符（分裂/巨大化/制导/反弹/贯穿/重力…）+ 2 触发器（撞击/定时）+ 3 辅助，槽位受“晶数”容量限制，法力耗尽即充能。
- **五层生物群系**：矿坑→煤坑→菌窟→冰渊→熔火之心，越深越强（敌人 tier 缩放、更危险的液池），层间有**圣所**（泉水回血/长桌/圣坛）。山顶基地是回城点。
- **敌人 7 种**：岩脊兽（近战追跳）、蝠灵（飞行俯冲）、游荡枪手（预判连射）、燃爆虫（自爆连锁）、掘地蠕虫（吞地穿行）、吐酸菌妖（抛物线酸弹）、腐毒胶母（跳跃滴酸）。关底 Boss「熔渊巨眼」460 HP、三阶段（弹幕/召唤/注视光束，低血狂暴）。
- **死亡必报死因**：烧死 / 熔岩 / 溺毙 / 酸蚀 / 毒发 / 压死 / 坠落 / 爆炸 / 被击杀 / 冰霜……死亡面板写明细节后可一键整局重来（新种子）。
- **手感**：屏幕震动、受击闪白、顿帧（hitstop）、火花/血雾粒子爆发、全程 **WebAudio 合成音效**（无音频文件）。

QA 过程中修出的真机级 bug（均为真实游戏缺陷，非测试桩问题）：光图模糊把整张光照缓冲逐行清零（全黑洞穴的根因）、`rowActive` 原位相变记账错误（沙埋/蒸汽冻结类卡顿）、世界重生未清空敌人/掉落物数组、法杖编辑器点击重渲染后事件目标失联、洞穴表引用了未实现的敌人类型（`slimer` 悬空键→现已实现为“腐毒胶母”）、出生点正对坠落竖井。

**性能**：jsdom（纯 CPU、无 GPU 合成、含全部 DOM 断言开销）实测模拟+渲染 100–276 帧/秒；真机浏览器以 `putImageData` 直写 480×270，满 60 FPS 余量充足。固定步长 60Hz 累加器 + 每帧最多 3 个补步 + 后台标签页自动暂停。

## 已知限制

- 触屏布局与 WebAudio 在无头 jsdom 中只能验证代码路径（音频图构建、coarse-pointer CSS），最终听感/手感请在真机浏览器确认。
- 模拟为邻域元胞自动机（非刚体引擎）：流体走经典 CA 近似，个别极端配置下液面会有 1px 抖动，属于此类实现常见现象。

# PIXEL ALCHEMIST · Noita 风格纯前端像素物理地牢

一款基于每像素物理模拟、动态黑暗光照与高度自由法术连锁的 Noita 风格纯前端 Roguelite 游戏。零后端、无构建依赖、单目录运行，还原 Noita 的核心物理、组装与探索机制。

---

## 快速开始

在仓库根目录下运行本地静态服务器：

```bash
python3 -m http.server 4173
```

在浏览器中打开：
```
http://localhost:4173/
```

## 核心系统还原与实现亮点

### 1. 像素物理与材料分层模拟 (Cellular Automata)
- **材料密度分层**：
  - **黑油 (Oil)**（密度 1.0）：浮于水、血、酸、熔岩之上，极易引燃，火势蔓延极快。
  - **水 (Water)**（密度 2.0）：灭火降温，沉于油底、浮于血与熔岩之上；可洗去玩家身上的毒浆与火焰。
  - **剧毒污浆 (Toxic Sludge)**（密度 2.5）：放射性绿色毒液，接触造成持续中毒伤害；水可将其稀释净化。
  - **血液 (Blood)**（密度 3.0）：沉于水和油之下，击伤击杀生物时喷溅沉淀，可浇灭火焰。
  - **强酸 (Acid)**（密度 4.0）：剧毒腐蚀性亮绿液体，接触任何固体（岩石、泥土、木材、神殿砖块）时均会持续溶蚀地形，沸腾产生上升的毒酸气！
  - **熔岩 (Lava)**（密度 5.0）：沉于最底层，温度极高；接触水或血时立即发生剧烈反应：熔岩凝固为玄武石（Lavarock），水分瞬间蒸发爆裂出大片上升蒸汽！
  - **粉末模拟**：砂砾 (Sand)、积雪 (Snow)、火药 (Gunpowder)、金砂 (Gold Dust) 具备自然安息角堆积，且因重力穿透液体沉入水底。火药接触火星时触发剧烈连锁爆燃！
- **材料贴图质感**：采用基于坐标哈希算法的颗粒噪点与地层纹理（花岗岩斑点、泥土颗粒、木纹条理、圣殿金边与砂石微光），彻底告别单调平涂色块。

### 2. 黑暗氛围与动态放射光照 (Darkness & Radial Lighting)
- **深渊黑暗**：地下洞穴被深邃阴影笼罩，营造原汁原味的幽闭探险压迫感。
- **动态放射光照剪切**：
  - **炼金术士提灯**：主角周身散发柔和温暖的径向衰减光晕。
  - **洞穴火把与铜炉**：墙壁火把具备自然的火光抖动与温暖橘色放射光。
  - **法术与弹体辉光**：火花弹泛起冷青光亮，烈焰球与爆炸释放耀眼橘红火光，发光钻头投射锋利激光光束。
  - **爆炸强光与光晕合成**：剧烈爆破瞬间点亮整间洞穴，配合叠加光晕（Bloom）渲染。

### 3. 法杖引擎与法术连锁组装 (Wand Crafting Engine)
- **4 把专属魔杖**：具备独立卡槽容量、施法延迟 (Cast Delay)、充能时间 (Recharge Time)、魔力上限、回复速度与乱序 (Shuffle) 判定。
- **完备的法术库**：
  - **8 种弹体 (Projectiles)**：火花弹 (Spark)、弹跳弹 (Bouncy)、魔法箭 (Arrow)、烈焰球 (Fireball)、不稳定炸弹 (Bomb，重力抛物线+碎岩爆破)、光明钻头 (Drill，瞬间切穿岩石+大幅降低延迟)、能量巨球 (Energy Orb)、小型黑洞 (Black Hole，吞噬途经一切物质)。
  - **3 种触发弹体 (Triggers)**：火花弹-带触发、魔法箭-带定时、传送弹-带触发。
  - **7 种修饰符 (Modifiers)**：三重散射 (Multicast)、追踪修饰 (Homing)、火焰轨迹 (Fire Trail)、重击强化 (Damage+)、弹跳修饰 (Bouncy)、爆炸修饰 (Explosive)、减耗加速 (Recharge-)。
- **连锁机制实现**：触发弹体在命中地形或敌人（或定时结束）时，自动捕获后续修饰符与弹体，并在落点爆发！玩家可自由组装出如 **【火花弹-带触发 + 三重散射 + 火焰轨迹 + 追踪 + 魔法箭】** 的毁灭性追踪火雨连锁。
- **交互式魔杖工作台 (Wand Workshop)**：在圣山（或拥有随处组装天赋）中按 `E` 键呼出，支持魔杖卡槽与法术背包之间的自由拖拽与点击互换，并提供详尽的属性面板与法术卡片悬浮检视。

### 4. 纵向深度地牢与探索循环 (Biomes & Holy Mountain)
- **8 层纵向生物群系**：矿坑 (Mines) → 煤坑 (Coal Pits) → 真菌洞穴 (Fungal Caverns) → 雪山深渊 (Snowy Depths) → 席西基地 (Hiisi Base) → 地下丛林 (Jungle) → 远古避难所 (The Vault) → 终焉实验室 (The Laboratory)。
- **中继圣山 (Holy Mountain)**：
  - 全生命恢复红心 (+10 生命上限并补满血量)
  - 奥术充能水晶 (恢复法术与魔力)
  - 天赋祭坛 (3 项随机永久天赋供三选一，如火焰免疫、剧毒免疫、随处编辑、玻璃大炮、强效悬浮、暴击直觉等)
  - 法杖商店基座 (使用收集的黄金购买新魔杖)
  - **激怒神明机制**：若用强酸、炸弹或巨蠕虫挖穿圣山砖块，屏幕剧烈震颤并出现警告 **"✦ 你激怒了神明... ✦"**，同时圣山守卫 (Stevari) 降临追杀！
- **可交互环境道具**：木制宝箱（按 F 开启或炸开掉落金币与法术）、炸药桶（可踢击与爆燃引爆）、强酸桶。

### 5. 差异化敌人 AI (Enemy Archetypes)
1. **席西矿工 (Hiisi Miner)**：近战冲锋，巡逻跳跃，见敌挥镐飞扑，受创喷洒鲜血。
2. **席西神射手 (Hiisi Sniper)**：拉开射距，开启红色激光瞄准线蓄力预警，射出高速狙击穿透子弹。
3. **剧毒飞蝠 (Toxic Bat)**：正弦波动飞行机动，从上方俯冲并喷吐剧毒酸滴。
4. **强酸自爆虫 (Acid Kamikaze)**：快速奔袭狂暴跳跃，近身或濒死时剧烈自爆，泼洒大片致命强酸与酸雾！
5. **深渊巨蠕虫 (Giant Cave Worm)**：多节身体结构，实时在地层中穿行并啃食崩解岩石，靠近时引发强烈地震与屏幕震颤，破墙咬杀玩家！
6. **圣山守卫 (Stevari)**：漂浮骨骸法师，身披能量护盾，发射追踪破坏性能量球。
7. **深渊主宰·终焉之眼 (Kolmisilmä)**：终层实验室巨型首领，三眼凝视，环绕能量旋盾，三阶段弹幕狂暴轰炸。

### 6. 打击感与程序化合成音效 (Feel & WebAudio)
- **震屏与打击反馈**：基于创伤衰减模型的动态震屏，受击时敌人纯白闪光 (Hit Flash)，暴击与伤害跳字。
- **实体物理喷溅**：击中敌人喷洒血液并沉淀为模拟液体，爆破产生烟尘、火星与冲击波。
- **100% Web Audio API 声音合成**：零外链音频文件，原生合成火花法术锐鸣、烈焰风暴呼啸、超重低音爆破音浪、硬币清脆双音阶、圣山神圣和弦与激怒神明的恐怖低音铜管。

### 7. 明确死因与统计 (Cause of Death)
- 严谨追踪玩家最终致死源头并在死亡界面明确宣告：
  - `死因：被烈火焚为灰烬`
  - `死因：在深水中溺亡`
  - `死因：被崩塌落石压死`
  - `死因：被强酸腐蚀融化`
  - `死因：剧毒腐蚀身亡`
  - `死因：被自己的法术爆炸炸飞`
  - `死因：被 [敌人名称] 击杀`
- 汇总深入深度、击败生物数、收集黄金总额、存活时间与最终魔杖配备。

## 操作指南

### 桌面键鼠
- `A` / `D` 或 `←` / `→`：左右移动
- `W` / `Space` 或 `↑`：跳跃与悬浮飞跃（消耗 LEV 燃料，松开自然回充）
- `S` 或 `↓`：下蹲 / 穿过平台
- **鼠标移动**：360 度十字准星瞄准
- **鼠标左键**：施放当前魔杖
- `1` / `2` / `3` / `4`：快速切换第 1 ~ 4 把魔杖
- `E` / `I`：打开 / 关闭魔杖组装工作台（仅在圣山或拥有天赋时可用）
- `F`：拾取魔杖、开启宝箱、购买商店道具
- `V`：踢击障碍物、炸药桶与生物残躯

### 移动端触屏
- 左下角虚拟方向键控制行走与悬浮
- 右下角大圆形触控按钮负责开火施法
- "换杖"、"组装"、"踢" 快捷触控按钮

## 本地无头实测记录 (Headless Chrome Verification)

我们在本地使用 Headless Chrome 与 Chrome DevTools Protocol (CDP) 进行了端到端真实游玩实测，所有核心系统测试均通过：

1. **出生点与移动实测**：
   - 玩家顺利出生于矿坑入口（x=160, y=59.9），初始血量 100/100，悬浮燃料 100/100。
   - `A/D` 键行走响应灵敏，X 坐标从 160.0 稳定平移至 171.8。
   - `W/Space` 悬浮升空顺畅，喷射魔法粒子，燃料消耗后着地自动充能。
2. **光照与黑暗渲染实测**：
   - 动态光照遮罩成功渲染，提灯以玩家为中心生成平滑径向衰减光晕；墙壁火把呈现 48px 波动火光；投射物发光正常。
3. **魔杖组装与连锁实测**：
   - 成功组装出【火花弹-带触发 + 三重散射 + 火焰轨迹 + 追踪 + 魔法箭】组合。
   - 弹体命中实体时，成功在碰撞点引爆后续 3 枚带火焰轨迹的追踪飞矢。
4. **战斗与敌人实测**：
   - 生成席西矿工与强酸自爆虫，火花弹击中后出现纯白受击闪光与浮动伤害数字，敌人死亡喷溅血液并掉落金币，击杀数递增。
5. **死因提示实测**：
   - 针对烈火、溺水、落石、强酸、毒液、自身爆炸、席西神射手狙击、深渊巨蠕虫等各类致死源进行验证，死亡弹窗 100% 精确显示对应死因横幅，并正确记录深度与战果。

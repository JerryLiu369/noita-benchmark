# PIXEL ALCHEMIST · 像素炼金术士

一个**纯前端、零后端、零构建**的 Noita 风格像素物理 Roguelite。
每一颗像素都参与模拟：固体、粉末、液体（按密度分层）、气体、火焰与炼金反应共享同一套网格；
洞穴是黑暗的，只有你的微光、火把、岩浆与发光法术能照亮周围；魔杖只是容器，真正的力量来自法术组合。

> 原创代码、原创像素绘制与原创命名；仅复刻公开可验证的**系统关系**，没有使用 Noita 的任何原始资源、音频或源码。

---

## 运行

```bash
cd /home/ubuntu/bench/noita-ds41
python3 -m http.server 4173
# 浏览器打开 http://localhost:4173/
```

不需要安装依赖、不需要联网、不需要构建步骤。三个文件即可离线运行：`index.html` · `styles.css` · `game.js`。

## 已实现的机制

### 1. 像素物理与材料（47 种）
- **分类**：固体、粉末、液体、魔法液体、气体、火焰。
- **密度分层**：油（0.82）浮在水（1.00）上；血（1.10）、黏液（1.20）沉入水底；岩浆（2.20）最重。
- **炼金反应**（节选自 `refs/wiki/Table_of_Alchemical_Reactions.md`）：
  - 岩浆 + 水 → 岩石 + 蒸汽；岩浆 + 冰/雪 → 水/蒸汽；岩浆引燃可燃物。
  - 火焰 + 水 → 蒸汽；火焰 + 冰/雪 → 水；火焰沿木材、煤、油、酒精、苔藓、菌类蔓延，也会熄灭。
  - 酸液溶解可腐蚀的固体与粉末，并冒出毒气；水稀释毒泥；水泥遇水凝固。
  - 毒泥/毒液会挥发出上浮的毒气；可燃气体遇火爆炸；火药遇火爆炸。
- **贴图质感**：每种材料有 2–4 个色阶变体，按坐标哈希选择（液体与火焰还会随时间流动），不是纯色块。

### 2. 黑暗与光照
- 低分辨率光照缓冲（160×90）+ **Dijkstra 式光传播**，实体阻挡光线，因此墙后自然形成阴影。
- **彩色光晕**：火焰（暖橙）、岩浆（橙红）、发光菇（紫）、酸液（绿）、魔液（蓝）、命泉（粉）、金矿/魔晶（微光）。
- 洞穴环境光很暗，只有**玩家微光**、**火把**、**发光法术**（照明修饰 / 钻头 / 闪电）与**岩浆/火焰**能照亮周围。
- 最终以「场景 × 光照」乘法合成，缩放到像素画布时使用双线性插值得到柔和径向渐变。

### 3. 法杖组装（核心系统）
- 魔杖是容器，属性包括：**乱序 / 顺序**、**施法延迟**、**充能时间**、**法力上限 / 回魔**、**容量**、**散射**、**固有施法**、**速度倍率**、**多重施法数**。
- **施法求值**：从左到右抽牌；修饰作用于其后的弹体；多重施法增加本次抽取数量；卡组耗尽时回绕并进入充能（乱序魔杖会重新洗牌）；法力不足则跳过/失败；有限次数的法术用尽后跳过。
- **触发 / 定时**：命中或计时结束后释放其载荷（载荷在抽取时确定，不额外耗蓝）。
- 数量：**17 种弹体、20 种修饰、4 种多重施法、4 种触发/定时**，共 45 种法术。
- 组合示例：`多重施法 → 追踪 → 火焰轨迹 → 火花弹`（一次三发、自动追踪、拖曳火焰）；
  `火花·触发 → 炎爆弹`（命中后原地引爆）。
- **编辑台**：圣山内按 `E` 打开，支持**拖拽**法术到槽位、点击两个槽位交换、右键清空、从「暂存法术」拖入、随机填入。

### 4. 探索与死亡
- 8 层纵向生物群系：**矿坑 → 煤坑 → 雪原深处 → 铁颚要塞 → 地下丛林 → 沉金秘库 → 棱光神殿 → 终焉实验室**，每层之间是**圣山**。
- 圣山提供：完全回复血瓶、魔杖编辑台、**三选一永久祝福**。
- 拾取：金币（自动吸附）、法杖（按 `F` 或点击）、宝箱（金币 + 法术）、额外生命。
- **永久死亡**，结算界面写明死因：**灼烧 / 溺死 / 窒息 / 中毒 / 熔岩 / 酸液 / 爆炸 / 被压死 / 摔落 / 被<敌人名>击杀**，并显示深度、击杀、金币、存活时间与种子。
- 击败终焉之核（首领）即通关。

### 5. 打击感
- 屏幕震动、命中闪白、暴击金闪、粒子爆裂（血、火花、爆炸、烟、碎片、治疗、传送）。
- WebAudio 合成音效（无音频文件）：施法、爆炸、命中、击杀、受伤、死亡、拾取、祝福、圣山、生物群系切换、通关；另有随深度变化的低频环境音。
- 受伤红屏、低血量暗角、冰冻蓝屏、命中伤害数字。

### 6. 敌人（12 种，行为有区分）
近战冲锋（矿工幽影）、远程点射（蜥人枪手 / 吐酸者）、飞行（洞穴蝠 / 幽灵）、自爆（自爆菌）、**掘地穿墙**（掘地虫）、跳跃喷毒（黏液怪）、固定炮台（炮塔）、传送施法（神殿法师）、火萤（投火）、首领（终焉之核：环形弹幕 / 追踪弹 / 召唤小怪）。
敌人有阵营、环境伤害与部分免疫，会受火焰/岩浆/酸液/中毒影响。

### 7. 桌面与移动端
- 键鼠完整支持；触屏提供方向、跳跃、施法、换杖、编辑按钮，施法自动瞄准。

## 测试与实测

仓库内置了可在无头 Chrome 中运行的自动化验证入口（不影响正常游玩）：

| 入口 | 作用 |
|---|---|
| `?selftest=1` | 基础玩法自检（出生、移动、跳跃、施法、击杀、炼金、光照、死因） |
| `?feature=1` | 全机制验证（生物群系、圣山、编辑台、连锁、触发、状态伤害、溺水、首领通关、连通性、性能） |
| `?playtest=1&ticks=N` | 机器人自动游玩（战斗 + 挖掘下降） |
| `?analyze=1` | 把游戏画布转成 ASCII / 统计，便于无头环境检查画面 |
| `?perf=1&biome=N` | 指定生物群系的性能测量 |

结果写入页面的 `data-selftest` / `data-feature` / `data-playtest` 属性，可用 `--dump-dom` 读取。

**实测结果（无头 Chrome，容器内；本机性能通常更好）**
- 自检全部通过：出生点可站立、能移动/跳跃、施法产生弹体、能击杀敌人、岩浆遇水生成岩石+蒸汽、油浮在水上、光照缓冲有亮区、死亡界面显示死因。
- 机制验证全部通过：8 个生物群系、47 种材料、45 种法术、22 种祝福、10 种敌人可生成并运行；
  连锁魔杖一次产生 3 发追踪火焰弹；触发法术命中后释放载荷；火焰/岩浆/酸液造成伤害；溺水死亡原因为「窒息」。
- 连通性：从出生点洪泛可达 y=2089（终焉实验室），无需挖洞即可一路向下。
- 性能：单帧逻辑约 3.5 ms（含像素模拟、光照与渲染），在常规机器上可稳定 60 FPS。
- 画面：出生点附近画布平均亮度约 26/255，近黑像素约 19%，发光材料与玩家光晕形成明显径向渐变。

更详细的交付说明与实测记录见 [`DONE.md`](./DONE.md)。

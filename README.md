# 深岩秘术 · DEEPROCK ARCANA

一个从零重写的、Noita 风格的纯前端像素物理 roguelite。没有后端、没有构建步骤、没有 npm 依赖、没有外部图片或音频素材。

- 世界尺寸：720 × 2960 像素，可视窗口 480 × 270，1 像素 = 1 个模拟单元
- 渲染：`<canvas>` + 逐像素贴图、光照遮罩、粒子、屏幕震动
- 物理：底部向上的 cellular automaton，液体密度分层、粉末堆积、气体上浮、火焰蔓延与熄灭、酸蚀、熔岩遇水成岩
- 音频：WebAudio 实时合成（环境低鸣、施法、爆炸、命中、受伤、金币、传送、胜利）
- 操作：桌面键鼠 + 手机触屏（虚拟摇杆 / 自动索敌开火 / 互动 / 换杖 / 暂停）

## 运行

```bash
cd /path/to/noita-ds1017
python3 -m http.server 4173
# 浏览器打开 http://127.0.0.1:4173/
```

不需要安装任何东西。建议使用 Chrome / Edge / Firefox 的较新版本。

## 已实现的机制

### 1. 像素材料模拟（60Hz）

- 34 种材料（含空气）：固体 / 粉末 / 液体 / 气体 / 火焰；密度、硬度、可燃性、燃烧时长、发光、酸抗性分别建模。
- 液体：油（密度 760）浮在水（1000）上，血（1060）下沉，酸（1180）、毒泥（1140）、熔岩（1500）继续向下分层；液体横向流动、斜向流下、与气体交换。
- 火焰：沿木头、煤、油、苔、菌肉、火药蔓延；需要燃料，燃尽转为灰/烟；遇到水、冰、酸会熄灭并产生蒸汽；熔岩会点燃邻近可燃物。
- 反应：熔岩 + 水/冰/雪 → 岩石 + 蒸汽；水 + 熔岩从上方接触也会结壳；酸缓慢溶解大部分固体；冰/雪受热融化；火药接触火/熔岩会连锁爆炸；毒气、蒸汽、烟上浮，蒸汽会在洞顶凝结成水。
- 粉末：砂、雪、灰、火药、金砂受重力堆积，能沉入比自身密度低的液体。
- 矿石被爆炸/钻头破坏时会掉落金币。
- 材质辨识：每种材料有 5 色随机纹理，并按材质叠加砖缝、木纹、金属铆钉、矿石金斑、冰的透明混色、液体表面高光、火焰动画等。

### 2. 黑暗与光照

- 洞穴整体变暗，深度越深越暗；灰烬圣所有暖色环境光，熔心区域有熔岩暖光。
- 玩家携带提灯光圈；火把、熔岩、火焰、荧光菇、晶簇、法术弹体、爆炸都会发光。
- 玩家/火把的光使用 72 条射线做墙体遮挡，只有视线可达的区域被照亮；熔岩/法术光使用无遮挡的彩色 bloom 叠加。
- 发光物在黑暗里仍会露出眼睛/核心的光点（敌人眼睛、法术球、金币、法杖）。

### 3. 法杖组装

- 4 个法杖槽位；可在地面/宝箱/商店拾取法杖，拾取时可直接替换当前杖。
- 编辑台支持点选交换、拖放、右键卸下；显示容量、每次施法数、施法延迟、充能、最大法力、回蓝、散射、乱序、始终施放、阶级。
- 牌序编译器：非乱序法杖从左到右读取；修饰法术作用于其后的投射物；多播/散射扩大本次施法；触发/延时法术会吞下后续法术作为 payload，命中/超时后在弹着点二次施法，支持最多 3 层嵌套。
- 法力消耗、每发延迟、牌堆清空后的充能、乱序随机起点均参与施法节奏。
- 法术内容：10 种投射物/功能弹（火花、秘法箭、炎团、孢囊弹、霜锥、雷弧、光钻、炸药、酸球、泉涌）、2 种触发（命中触发、延时触发）、11 种修饰（追踪、重型、疾速、火焰尾迹、爆裂、弹射、穿透、散射、三重施法、节能、延寿）。
- 连锁示例：`散射 → 追踪 → 火花·触发 → 炎团` 会打出 3 枚追踪火花，每枚命中后各释放一枚炎团。

### 4. 探索、圣所与死亡

- 7 个纵向区域 + 地表：苔语林 → 旧铜矿坑 → 焦煤深坑 → 菌光洞窟 → 霜喉裂谷 → 锈铁堡垒 → 熔心祭坛 → 熔心之底（Boss）。
- 每层之间有灰烬圣所：首次进入回满生命/法力、三选一祝福、商店（血瓶/法术卷轴/法杖）、魔杖祭坛、下行传送门。
- 地形程序生成：噪声洞穴 + 蜿蜒主路 + 圣所竖井 + 保证连通的横向隧道；使用洪水填充验证过主路/圣所/Boss 均可达。
- 战利品：金币（磁吸）、血瓶、宝箱（金币 + 法术/法杖/血瓶）、地面法杖、法术球、商店。
- 死亡会显示明确死因（烧死、熔岩焚身、溺死、酸蚀而死、毒死、被炸死、被压死、摔死、被击杀、被法术击杀），并附击杀者/环境细节、最深处、击杀数、金币、存活时间；点击「再入深渊」生成新种子重开。
- 祝福（15 种）：石肤、玻璃之怒、焰血、毒血、羽落、游方匠、贪欲、血契、浮空核、再生、爆免、磁吸、食髓、疾行、残响护盾。

### 5. 打击感与音频

- 屏幕震动（爆炸/暴击/受伤）、命中白闪与暴击金光、血液/碎屑/火花/烟尘/气泡粒子、爆炸冲击环、低血量红色边缘。
- WebAudio 合成：不同法术音色、爆炸噪声、命中、受伤、金币、治疗、开箱、传送、圣所钟声、Boss 低频施法、死亡下滑音、胜利和弦；环境低频 drone。

## 实测记录

测试日期：2026-10-18。环境：本机 `python3 -m http.server 4173`，Chrome 153 headless（CDP 驱动真实键鼠/触摸事件），960×540 与 1280×720 窗口。

- **启动与移动**：点击标题按钮生成随机种子；出生点站地，`D` 移动 1.2 秒位移 48px；`W` 起跳/悬浮正常；能施法并产生粒子与短促音效。
- **战斗**：自动瞄准并真实按住鼠标左键，击杀出生点附近的岩背獠；`火花·触发 + 炎团` 连锁把一只满血岩背獠从 38.4 HP 打到 0.4 HP；另一次触发链测试直接击杀。
- **长时巡游**：约 **91.7 秒**，跨 6 个区域，**击杀 3 只**，最深处 **2404m**，金币 58；巡游过程中无控制台异常。
- **死亡提示**：分别验证 `被击杀`（「被岩背獠撕开」，75m，1 击杀，0:04）、`烧死`、`熔岩焚身`、`溺死`、`被压死`、`毒死`、`被炸死`，全部在死亡卡片中显示死因与细节。
- **圣所 / 商店 / 传送**：进入灰烬圣所自动回满并弹出 3 张祝福；选择祝福后传送门解锁，实际按 `E` 下行至焦煤深坑（y≈838，深度 751m）；商店购买血瓶扣除 40 金币，宝箱开启、拾取法杖、编辑台换槽均正常。
- **Boss**：用测试杖在约 8.4 秒内把熔心巨眼从 1250 HP 打到 295 HP；Boss 死亡流程触发胜利结算页。
- **光照**：地表平均亮度约 42–46（亮），矿坑/焦煤/堡垒约 17–25（暗且可辨），雪原约 49，熔心约 43（熔岩光）；玩家提灯、火把、岩浆、法术光均可见。
- **性能**：深部洞穴实测 52–60 FPS（480×270 内部渲染，Chrome headless / SwiftShader）。
- **连通性**：对静态世界做 4 邻域洪水填充，出生点可到达 **1212 / 1232** 个主路采样点、**5 个灰烬圣所**和 **Boss 房**；可达空气约占世界空气的 22%。
- **手机**：844×390 触摸模拟下虚拟摇杆、跳跃、自动索敌开火、互动、换杖、暂停均可用；触摸 `✦` 按钮实际击杀岩背獠。
- 最终冒烟测试无 `Runtime.exceptionThrown` 控制台异常。

## 已知边界

这是机制复刻而不是 Noita 的完整移植：没有全部 422 个法术、没有炼金配方书、没有平行世界/魔球/结局分支；部分材料（金粉、骨）只作为地形/装饰存在。所有美术、名称、音效均为本项目原创代码生成。

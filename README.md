# 深井余烬 / Ember Deep

一个原创像素物理洞穴游戏，依照 `TASK.md` 与本地参考资料全面重做。直接进入可玩的矿坑，沿五层洞穴向下探索，组装魔杖，在静火驿站休整，挑战赤核守卫。死亡后整局重开。

## 运行

```bash
python3 -m http.server 4173
```

打开 <http://localhost:4173/>。运行时只有 `index.html`、`styles.css`、`game.js`，无需构建、npm、联网或后端服务；也可直接打开 `index.html`。

默认每次重开使用新种子。`?seed=84321` 可固定地形以便复测，固定种子模式下重开会重建相同地形，但清空本局状态。

## 操作

| 操作 | 桌面 | 手机 |
| --- | --- | --- |
| 移动 | A / D 或左右方向键 | 左下左右按钮 |
| 跳跃、悬浮 | W / Space / 上方向键，按住消耗悬浮储量 | 按住上箭头 |
| 瞄准、施法 | 鼠标瞄准，按住左键 | 按住右下施法盘并向目标方向拖动；也可直接按住场景目标 |
| 切换魔杖 | 1–4、滚轮或点击魔杖栏 | 点击魔杖栏 |
| 开宝箱、拾杖、编辑 | E 或点击出现的交互按钮 | 点击交互按钮 |
| 编辑法术 | 在魔杖槽位与储物格间拖放，或依次点击两格交换 | 同样支持触屏拖放与两次点击交换 |
| 暂停／返回 | Esc 或右上暂停按钮 | 右上暂停按钮 |
| 音效、震动 | 右上音符开关；暂停菜单可切换两项设置 | 同左 |

离开页面会自动暂停并释放按键。音效默认关闭，开启后通过 WebAudio 合成。编辑时游戏暂停；只有驿站或“流浪工匠”天赋允许编辑。Tab、Enter 与数字键可操作相应菜单。

## 机制

- **五层探索**：锈脉矿坑 → 余火煤层 → 荧孢深林 → 霜裂冰窟 → 赤核熔炉。随机支洞与保证连通的主路径，层间驿站、终层守卫、胜利和死亡结算。
- **材料物理**：22 种材料状态，粉末下落，油浮水上、血沉水下，火焰沿木材／油／煤／苔藓蔓延并耗尽，水与血灭火，熔岩遇水成石与蒸汽，蒸汽凝结，酸蚀产生上浮毒气。岩层具有破坏阈值和硬度能量消耗。
- **画面与反馈**：原创像素角色、石纹、木架、根系、菌伞、冰柱和砖砌驿站；独立径向黑暗遮罩；持杖微光、火把、熔岩、法术及爆炸光照；命中闪光、粒子、震动与合成音效。
- **法杖组装**：4 个魔杖位，开局 2 把，固定槽容量，12 格法术储物格。7 弹体、5 修饰、碰撞／定时两种触发；从左向右执行，修饰只作用于后续弹体，嵌套载荷魔力预付，槽末取施法间隔与充能时间的最大值。
- **战利品与成长**：金币、恢复 30 生命的血瓶、宝箱、魔杖、法术；满 4 把时明确选择替换，旧杖留在地上。每座驿站完整恢复一次、天赋三选一一次，并提供有限的付费法术。
- **危险与敌人**：预备后冲锋的角甲、检查视线的弹幕射手、追逐飞行的夜翼、引信自爆的爆囊、挖穿岩层的钻脊，另有赤核守卫。湿润、油污、燃烧、毒素和空气储量参与伤害。没有玩家坠落伤害，挤压来自真正下落的石块。

可用组合：把“三重散射 → 引燃 → 寻踪 → 辉针”依次放入同一把魔杖；或者“碰撞引信 → 定时引信 → 寻踪 → 烬火球”。这些法术要从储物格、宝箱或驿站取得。

## 实测记录

2026-09-05，使用本地 `4173` 静态服务器与 Chrome 无头浏览器，通过 CDP 注入真实键鼠／多点触屏事件。

**连续自然游玩**：种子 `84321`，约 **52.3 秒墙钟时间、50.7 秒有效游戏时间**，从出生区走跳、施法，开启宝箱，在第一座驿站实际拖放组装“散射＋引燃＋寻踪＋辉针”，经过全部五层与五座驿站，**击杀 19 只敌人、获得 452 G、深入 1939 m**。在终层守卫处死亡，结算明确显示 **“死因：被击杀”**。没有直接修改角色生命、敌人或地形来完成这段游玩，也没有自然通关。

**自动回归与控制场景**：验证自然出生移动／跳跃／至少一次击杀、非空画面与不透明光照合成、5 种种子的全层连通和敌人出生空间、材料密度／反应／燃尽／毒气／挖掘能量、法术顺序与嵌套触发、魔力预付和充能、桌面与触屏拖放、驿站恢复／单次天赋／付费藏品、重开清空状态。五种死因“烧死／溺死／压死／毒死／被击杀”分别通过控制环境中的正常伤害路径出现；这些是测试夹具，不冒充五次自然死亡。

桌面 `1440×900`、`1920×1080`，手机 `390×844`、`320×568`、横屏 `844×390` 已检查截图；手机多指同时移动、悬浮与拖动瞄准施法正常，松手停止输入，画面不拉伸、页面无横向溢出。窄屏交互按钮与魔杖栏已单独检查。浏览器运行时异常为 0。首领胜利面板另用受控击杀验证，未计入自然游玩战绩。

## 复跑检查

保持静态服务器运行，另一个终端执行：

```bash
node --check game.js
node scripts/verify-game.mjs
```

需要 Node 和 Chrome，可用 `CHROME_BIN` 指定 Chrome 路径。脚本自行启动并关闭测试浏览器，不安装依赖；截图和 JSON 结果写入被 Git 忽略的 `test-results/`。材料、死亡和深层通路测试使用明确的控制场景。

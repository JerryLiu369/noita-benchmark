# PIXEL ALCHEMIST · 像素炼金地牢

一个零后端、纯前端的 Noita 风格像素物理 roguelite。仓库只有三个文件：`index.html` / `game.js` / `styles.css`，
无构建步骤、无 npm 依赖、无外部素材（像素画、音效全部程序生成）。

## 运行

```bash
python3 -m http.server 4183      # 本机 4173 被其他进程占用时换端口即可
```

浏览器打开 `http://localhost:4183/`。桌面键鼠与手机触屏均可游玩。
可加 `?seed=12345` 固定种子复现同一局。

## 玩法循环

1. **地表营地**出生，两把起始杖：`旅人法杖`（星火弹×2，战斗）与 `矿工法杖`（穿日钻+引水术，挖掘/工具）。
   营地中央的洞口正对**主竖井**，一路向下。
2. 五层生物群系逐层恶化：**矿坑深巷 → 煤屑矿坑 → 荧光真菌窟 → 霜雪冰窟 → 熔岩深渊**，
   尽头是首领**熔渊之瞳**。每层之间有一座**圣山**。
3. **圣山**是安全区：圣泉（回满 HP/魔力并刷新法术次数）、祝福祭坛（三选一永久祝福）、
   **魔杖工坊**——把法术卡**拖进槽位**（触屏可拖），自由组合 弹体/修饰/触发/多重。
4. 死亡**写明死因**（烧死 / 溺死 / 压死 / 毒死 / 被击杀 / 炸死 / 熔岩吞没 / 腐蚀而死 / 冻死），
   附凶手、深度、击杀数、金币、存活时长与种子，然后整局重开。

## 已实现（对照 refs/ 蓝本）

### 像素物理（refs/wiki/Materials.md、Table_of_Alchemical_Reactions.md）
- 30 种材料，按 wiki 的**密度表**分层：油（0.80）浮于水（1.00）之上、血（1.10）沉到水下、
  熔岩（2.60）沉底、毒泥（1.18）居中；气体按密度上浮。
- 粉末（砂/碎石/雪/金沙）下落、斜流、休止角；液体下落+横向摊开（黏度不同：黏液慢、水快）；气体上升扩散。
- 炼金反应（对照反应表）：**熔岩+水 → 岩石+蒸汽**、熔岩+血/黏液同理、熔岩遇冰融水、
  酸液腐蚀一切（对照耐久阈值：钢架/圣山砖石抗酸）、水净化毒泥、蒸汽凝结回水、冰雾遇水结冰、
  可燃气遇火燃烧并可能爆燃。
- **火焰沿可燃物蔓延**：可燃固体先蓄热再起火（木梁/煤层/苔藓/菌块/荧光菇/泥土），油与酒直接点燃，
  遇水被扑灭并蒸腾；火焰升腾、寿命耗尽化烟。
- 耐久/硬度体系（wiki Durability/Hardness）：穿日钻可挖岩石（dur 10）挖不动钢架（13）；
  爆炸按 10 条射线消耗"射线能量"，硬岩只啃掉浅层，软煤整片崩落（并留下碎石，可能把人**压死**）。
- 材料接触伤害按 wiki 每帧每像素 DPS 折算：酸 7.5/s、熔岩 4.5/s、毒 1.5/s，且**无视无敌帧**。

### 黑暗与光照（refs/lighting.txt、实机截图 ss_00~07）
- 洞穴环境光接近全黑（每群系独立暗色），只有**玩家灯笼、火把、熔岩、火焰、荧光菇、发光法术、
  爆炸闪光**照亮周围，全部走**径向渐变光晕**（缓存的径向光斑贴图）。
- 主光源（玩家、火把）带**遮挡射线**：24 条射线对像素网格求交，生成可见性多边形做剪辑，形成真实投影。
- 合成链：场景 × 光照图（multiply）→ 大光源泛光（bloom）→ 暗角/入水罩/低血红晕/致盲半径。
- 自发光材料（熔岩/火焰/酸/毒气/冰雾/荧光菇）邻近合并成组光源，避免叠成白斑。
- 每种材料都有**贴图质感**（岩纹/斑点/颗粒/木纹/砖缝/液面高光/火焰渐变/矿脉/菌盖），没有纯色块；
  静态材料像素做了颜色缓存（性能）。

### 法杖组装（refs/wiki/Wands.md、Spells.md、wand_ui.txt）
- **牌库模型**：顺序序左→右抽牌；修饰累积进本次施法；多重牌扩容；弹体消耗一次施放；
  **触发/定时弹体吞掉后续牌作为载荷**，命中/到时在落点放出（"星火弹·触发 + 爆化"这类组合）。
- 魔杖属性照 wiki：`施法延迟 / 充能时间 / 魔力 / 魔力回复 / 容量 / 多重 / 散布 / 混乱序`，可带**常驻法术**。
  牌库抽空或绕回后进入充能；魔力不足的牌自动跳过（wiki 行为）。
- **27 种法术**：9 弹体（星火弹/铁羽箭/炎爆珠/裂地雷/黏液弹/刃环/冰晶刺/玄雷/穿日钻）、
  3 触发/定时（星火弹·触发/铁羽箭·触发/定时珠）、9 修饰（追踪/重击/急速/火焰尾迹/弹射/暴击/爆化/节能/贯穿）、
  3 多重（双重/三重/扇形五重）、3 工具（短距传送/治愈微光/引水术）。
- **魔杖工坊**：法术卡在"法术袋 ↔ 槽位 ↔ 别的法杖"之间**拖拽**（鼠标/触屏，含轻点选中再放置），
  双向交换、随时可见 8 项魔杖属性。世界里的法杖台可拾取/交换法杖（E）。

- 5 层群系 + 5 座圣山 + 首领熔岩厅；主竖井正对出生洞口，越深越蜿蜒（生成后二次疏通防堵塞）。

## 研究依据与边界

研究摘要与来源见 `report-source.md`；设计蓝本为 `refs/`（材料/反应/法杖/敌人/群系/状态/圣山 wiki 摘要
与官方实机截图 ss_00~07 的色调、光照与粒子密度）。实现使用原创代码、原创像素绘制与原创命名，
仅复刻公开描述的机制关系；没有复制 Noita 的原始资源、音频或源代码。
原作包含数百种法术、材料、敌人、隐藏平行世界与精确内部数值，本项目把最能决定手感的系统
（每像素物理、密度分层、炼金反应、黑暗光照、法杖牌库组装、状态与死因、永久死亡循环）
做成了可玩的浏览器版本，并保留了近似数值。

`game.js` 末尾暴露 `window.__game` 测试钩子（快照/定位/造怪/挖探针等），
仅供无头浏览器验收脚本使用，正常游玩不受影响。
